# Inventory Intelligence System: E-commerce Laptops 💻📦

## 📌 Professional Context
As a Junior Data Analyst with 8 years of experience in technology retail, I developed this project to automate inventory decision-making. This system transforms raw sales data into actionable KPIs for stock optimization and profitability.

## 🚀 Key Performance Indicators (KPIs)
The project consists of four specialized Python scripts:

* **Inventory Days Analysis (`kpi_inventory_days.py`)**: Calculates the average time products stay in stock to optimize cash flow.
* **Critical Stock Alerts (`kpi_critical_stock.py`)**: Identifies minimum units required per SKU based on daily demand and a 7-day lead time to prevent stockouts.
* **Profit Margin Analysis (`kpi_profit_margin_analysis.py`)**: Estimates profitability by category (Electronics vs. Computing) to prioritize high-margin investments.
* **Exploratory Data Analysis (`exploratory_data_analysis.py`)**: Automated overview of sales trends and product performance.

## 🛠️ Tech Stack
* **Language**: Python 3.x
* **Libraries**: Pandas (Data Manipulation)
* **Data Source**: `orders_dataset.csv` (Standardized sales data)
* **Visualization**: Power BI (Executive Dashboard)

## 📂 Project Structure
* `orders_dataset.csv`: Cleaned and standardized dataset.
* `*.py`: Modular Python scripts for specific KPI calculations.
* `Executive_Inventory_Dashboard.pbix`: Interactive dashboard for executive reporting.
