## 📌 Professional Context
As a Junior Data Analyst with 8 years of experience in tech retail, I developed this project to automate inventory decision-making. This system transforms raw sales data into actionable KPIs for stock optimization and profitability, bridging the gap between sales floor experience and data science.

## 🚀 Key Performance Indicators (KPIs)
The project utilizes modular Python scripts to address specific business questions:

* **Inventory Days Analysis (`kpi_inventory_days.py`)**: Measures cash flow efficiency by calculating how long stock sits in the warehouse.
* **Critical Stock Alerts (`kpi_critical_stock.py`)**: Uses a 7-day lead time logic to trigger restock alerts before a stockout occurs.
* **Profit Margin Analysis (`kpi_profit_margin_analysis.py`)**: Segmented analysis to prioritize high-performance computing categories.
* **Exploratory Data Analysis (`exploratory_data_analysis.py`)**: Initial diagnostic of the dataset to identify outliers and sales seasonality.

## 🛠️ Tech Stack & Methodology
* **Language**: Python 3.x (Pandas for data wrangling).
* **Visualization**: Power BI (Executive Reporting).
* **Versioning**: Git/GitHub (Professional workflow).

## 💻 How to Run
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Execute any KPI script: `python kpi_critical_stock.py`
